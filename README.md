# 📊 振幅监控 (Amplitude Monitor)

单K线振幅盯盘工具，实时监控 Binance 永续合约 U 本位交易对的 K 线振幅。

## 功能

- **多时间周期**: 5m / 15m / 30m / 1h / 4h / 1d
- **实时数据**: WebSocket 推送，毫秒级更新
- **四级预警**: 正常 → 警告 → 高危 → 极端，颜色 + 声音 + 浏览器通知
- **灵活阈值**: 加密货币 / 宽松 / 严格 三档预设，支持自定义
- **单币自定义**: 每个币种可独立设置振幅阈值
- **排序筛选**: 按字母/涨跌幅/各周期振幅排序，支持仅显示极端/已告警
- **告警记录**: 右侧面板查看历史告警

## 使用

浏览器打开 `index.html`，或通过 GitHub Pages 访问。

快捷键：`M` 静音 / `R` 刷新 / `S` 设置 / `A` 告警面板

## 数据源

[Binance Futures API](https://binance-docs.github.io/apidocs/futures/en/)
