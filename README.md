# 📈 单K涨幅榜 (Gain Monitor)

监控 **涨幅前 200 个币** 的 **单K线当前涨幅**（本K开盘价 → 现价），Binance U 本位永续合约，纯前端单文件。

在线版：<https://tusiyivip-source.github.io/amplitude-monitor/>

## 核心口径

- **涨幅 = (现价 − 本级别当前K线开盘价) / 本K开盘价**，K线一换就归零重算（不是级别内振幅，也不是滚动区间涨幅）
- **候选池**：全部 USDT 永续合约（约 500 个，24h 成交额 ≥ 100 万 U），实时排出 **前 200**
- **榜单依据**可切：本级单K涨幅 / 24h涨跌；**方向**可切：涨幅榜 / 跌幅榜

## 级别（标头直接点）

`10m / 15m / 30m / 1h / 2h / 3h / 4h / 6h / 12h / 24h`

> 币安合约没有 10m 与 3h 原生周期，页面用 **10m = 5m×2**、**3h = 1h×3** 合成，桶起点与开高低收已与原始K线逐字段核对一致。

## 功能

- **右侧实时K线图**：点左侧任意币种即联动显示当前级别K线；滚轮缩放、十字光标、成交量；黄色虚线为本K开盘基准线（策略基准），红绿蜡烛与表格一致
- **表格列**：排名 / 币种 / 现价 / 本级涨幅 / 本K开盘 / 本K振幅 / 24h涨跌 / 24h额，实时重排
- **四级预警**：正常 → 警告 → 高危 → 极端（阈值按级别可调，含默认/宽松/严格三档预设），颜色 + 声音 + 浏览器通知 + 钉钉机器人推送
- **单币自定义阈值**：每个币种可按级别独立设置
- **告警记录**：右侧面板查看历史告警，支持"仅极端/高危""仅已告警"筛选
- **数据源自适应**：WebSocket 实时推送；若 WS 静默 >15s 自动降级 REST 轮询（状态栏"数据源"可见）
- **防封限流**：每分钟请求预算（1200）+ 命中 418/429 时按 Retry-After 自动暂停，避免 IP 被币安限流封禁

## 使用

浏览器直接打开 `index.html`（或访问上方 Pages 地址）。

快捷键：`1`~`9`、`0` 切换级别 / `M` 静音 / `R` 刷新 / `S` 设置 / `A` 告警面板 / `Esc` 关闭弹窗

## 数据源

[Binance Futures API](https://binance-docs.github.io/apidocs/futures/en/)（REST + WebSocket）

## 钉钉推送

设置（`S`）→ 钉钉机器人推送：填 Webhook，可选自定义 CORS 代理，可测试推送。
